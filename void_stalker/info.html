🎮 El juego (versión SGDK)

Es un shmup vertical clásico para Mega Drive/Genesis con:
  • Nave del jugador con movimiento 8-direccional, disparo y power-ups
  • 3 tipos de enemigos: patrón senoidal, caída recta, y shooter con mira al jugador
  • Jefe de fin de oleada con escudos laterales y patrón de disparo circular
  • Sistema de oleadas: oleadas progresivas, cada 3ª oleada spawnea shooters
  • Power-ups: Spread shot, Bombas, Escudo temporal
  • Colisiones balas-enemigos, enemigo-jugador, power-ups
  • Partículas de explosión gestionadas en un manager separado (fx_world)
  • Pausa total: congela entidades del mundo usando darken_entity_pause/resume
  • HUD: puntuación, oleada, vidas y bombas
  • Fondo estrellado con scroll vertical en el plano B
  • Screen shake al recibir daño o destruir al jefe

Cómo compilar con SGDK

bash
Copy
# Estructura de carpetas SGDK típica:
#   mi_shmup/
#     src/main.c
#     inc/darken.h
#     out/          (se crea al compilar)

# Copia main.c a src/ y darken.h a inc/
# Desde la raíz del proyecto:
%GDK_WIN%\bin\make -f %GDK_WIN%\makefile.gen
No necesitas archivo .res — todos los gráficos se generan desde código (tiles 8x8 dibujados con arrays de u32).

🏗️ Arquitectura del código SGDK

plain
Copy
main.c
├── setup_vdp()          → Carga tiles, paleta, fondo estrellado
├── darken_init()        → 2 managers: world (juego) + fx_world (partículas)
│
├── Estados (callbacks Darken)
│   ├── state_player_alive()         → Input, disparo, movimiento
│   ├── state_player_invulnerable()  → Frames de invencibilidad
│   ├── state_enemy_sine()           → Movimiento ondulado (tabla seno)
│   ├── state_enemy_shooter()        → IA + spawn de balas dirigidas
│   ├── state_boss_attack()          → Patrón seno + escudos + disparo radial
│   ├── state_bullet_fly()           → Movimiento lineal, autodestrucción
│   ├── state_powerup_fall()         → Caída + parpadeo
│   └── state_particle_fade()        → Vida limitada, movimiento drift
│
├── Spawners
│   ├── spawn_enemy()      → 3 tipos con destructores que encolan explosiones
│   ├── spawn_boss()       → Jefe + 2 escudos como entidades vinculadas
│   └── spawn_particle()   → Manager fx_world separado para eficiencia
│
├── check_collisions()     → Doble bucle: balas→enemigos, enemigos→jugador
├── update_wave()          → Spawner progresivo, trigger de jefe
│
└── render_entities()      → Limpia plano A, dibuja tiles por entidad
    └── render_hud()       → VDP_drawText para score, vidas, mensajes
El código usa dos managers Darken (world y fx_world) para separar la lógica de juego de los efectos visuales, aprovechando que DARKEN_STORAGE fija el tamaño de payload por manager. Las partículas (payload pequeño) no penalizan el caché de las entidades de juego (payload grande).
